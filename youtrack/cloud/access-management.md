# Access Management

The Access Management section of the Administration menu links to pages that let you manage access to YouTrack. To access these links, click ![](https://resources.jetbrains.com/help/img/youtrack/2026.2/settings.svg) Administration in the main navigation menu, then select Access Management.

![The Access Management section of the Administration menu.](https://resources.jetbrains.com/help/img/youtrack/2026.2/access-management-administration-menu.png)

User access in YouTrack is defined on a per-project basis by the roles that are assigned to a user. A role is a set of permissions, which in their turn allow users to perform particular operations in YouTrack. Please note that permissions are only granted by assigning roles, and not directly.

Generally, users inherit roles from the groups they belong to. In cases when inherited roles do not provide the appropriate level of access, you can assign a role to a user account individually.

> **Tip: Permissions**
> To configure user access, you need several different permissions. These permissions are granted by default to the System Admin role.

We suggest that you configure user access in the following order:

1.  [Create new roles or configure predefined roles](create-and-edit-roles.html).

2.  [Create new groups or configure predefined groups](create-user-group.html).

3.  [Assign roles to groups on a per-project basis](configure-access-for-a-user-group.html#grant-role-to-group).

4.  [Create user accounts or enable self-registration for users](create-user-accounts.html).

5.  [Enable and configure auth modules](managing-auth-modules.html).

6.  [Configure group membership for YouTrack users](configure-group-members.html).
