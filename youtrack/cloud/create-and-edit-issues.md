# Create and Update Issues

If your project team uses YouTrack, the first thing you'll probably do is create an issue or two. If you've read the [quick start guide](reporting-an-issue.html), you already know how easy it is. On this page, you'll find a little more information about how to create an issue, add an attachment, and update existing issues.

## Create an Issue

Whenever you need to report a problem or define a task for yourself or another member of your project team, create an issue for it.

Procedure: To create an issue:

> **Tip:**
> Requires permissions: Create Issue, Update Issue, Add Attachment

1. From the main navigation, select ![](https://resources.jetbrains.com/help/img/youtrack/2026.2/issues.svg) Issues.

2. Press `Alt` + `Insert`, or click the New issue button in the header.

Press `Control` + `N`, or click the New issue button in the header.

There's also an ![](https://resources.jetbrains.com/help/img/youtrack/2026.2/add.svg) icon for adding a new issue next to the Drafts menu in the issue sidebar.

* The form for reporting a new issue opens as a dialog. ![The form for reporting a new issue.](https://resources.jetbrains.com/help/img/youtrack/2026.2/new-issue-form-lite.png)

To open the form in its own page, click the ![](https://resources.jetbrains.com/help/img/youtrack/2026.2/expand-all.svg) View in full page link at the bottom of the form.

3. YouTrack normally sets the value for the project field to the project where you reported your last issue.

To report the issue in another project, select another value for the Project field.

4. Enter an issue summary and description in the corresponding input fields. When you enter the description, you can format your text in Visual or Markdown mode.

* To learn more about formatting text in YouTrack, see [Rich Text Editor](rich-text-editor.html).

* For a complete list of formatting options in Markdown, see [Markdown Syntax](youtrack-markdown-syntax-issues.html).

5. Assign values to the custom fields. Default custom fields include the issue type, priority, and subsystem.

For more information about custom fields, see [Update Field Values](update-field-values.html).

6. To attach files to the issue:

* Click the attachment panel to select one or more files from your local directory.

* Drag files from your computer and drop them in the attachment panel.

* Press `Ctrl` + `V` to paste an image from your clipboard.

For additional options, click the ![](https://resources.jetbrains.com/help/img/youtrack/2026.2/more-options.svg) Show more button in the issue toolbar. For details, see [Attach a File or Screenshot](#attach-file-screenshot) below.

7. Do one of the following:

* To report the new issue, press `Ctrl` + `Enter` or click the Create button.

* Open the menu next to the Create button, where you can either choose to create the issue and load another empty draft or load another copy of the current issue. ![Menu for creating an issue and loading another draft of copy.](https://resources.jetbrains.com/help/img/youtrack/2026.2/create-and-load-another-lite.png)

* To close the New Issue page without reporting the issue, press `Esc` or click the Cancel button. The current issue is saved as a draft. The next time you create an issue, you can reload the draft from the Drafts menu in the sidebar.

> **Note: Creating Linked Issues**
> If you're reporting an issue and want to create one or more issues that are somehow connected to the issue you're currently working with, you can create and link multiple issues without leaving the current draft.
>
>
>
> To create an issue that is automatically linked to the current issue, use the Link issue option at the bottom of the form.
>
>
>
> * Choose which link type you want to use to bind the current issue with its target.
>
> * Use the search box to find existing issues.
>
> * To create an issue and link it to the current draft, enter the summary for the new issue and press `Enter` or click the Create link at the bottom of the search results.
>
>
>
> ![Options for linking issues to the current draft.](https://resources.jetbrains.com/help/img/youtrack/2026.2/add-subtasks-new-issue-lite.png)
>
> To learn more about linking issues in YouTrack, see [Link Issues](link-issues.html).

## Attach a File or Screenshot

Sometimes, words are not enough. To describe an issue in more detail, you can attach resources such as log files and screenshots to the issue.

Procedure: To attach a file or screenshot to an issue:

> **Tip:**
> Requires permissions: Read Issue, Update Issue, Add Attachment

1. From the main navigation menu, select ![](https://resources.jetbrains.com/help/img/youtrack/2026.2/issues.svg) Issues.

2. Open the issue where you want to add a file or screenshot.

3. Click the ![](https://resources.jetbrains.com/help/img/youtrack/2026.2/more-options.svg) Show more button in the toolbar.

4. Select one of the following options:

| Option | Description |
| --- | --- |
| Attach file | Select one or more files from your local directory and attach them to the issue. |
| Attach files privately | Select one or more files from your local directory and set the visibility of the attachments. Use this option when the attachments contain information that should be restricted to specific users or groups. |

You can also attach files by:

* Clicking the drop zone for attachments and selecting one or more files from your local directory.

* Select and drag one or more files to the drop zone.

For more information about attaching files or screenshots to an issue, see [Attach Files](add-an-attachment.html).

## Edit an Existing Issue

Nobody's perfect. If you want to rewrite the issue summary or description, you can change these at any time. All changes are recorded and displayed in the issue history. There are a few properties that you cannot update, like the issue ID, reporter, and creation date. These properties are saved by YouTrack and cannot be overwritten.

Procedure: To edit an existing issue:

> **Tip:**
> Requires permissions: Read Issue, Update Issue

1. If you're currently viewing the list of issues, you can either open the issue in preview mode or single issue view.

2. Click the ![](https://resources.jetbrains.com/help/img/youtrack/2026.2/pencil.svg) Edit issue button in the toolbar.

If the issue is open in preview mode, you can press `F2` on your keyboard.

* The issue opens in editing mode.

3. Update the project, summary, or description. You can also set new values for the custom fields.

4. When finished, click the Save button.

You can also apply changes to multiple issues with commands. For more information, see [Update Issues with Commands](commands.html).
