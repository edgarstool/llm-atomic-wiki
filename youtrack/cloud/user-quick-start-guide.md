# New User Quick Start Guide

If you are new to YouTrack, we recommend that you take a look at the following topics.

| Topic | Description |
| --- | --- |
| [Create and Update Issues](create-and-edit-issues.html) | Learn the basic steps for creating and updating issues. |
| [Attach Files](add-an-attachment.html) | Flesh out issues by attaching images and files. |
| [Watch Issues](watching-issues.html) | Track the progress of particular issues by adding them to your watch list. |
| [Tag Issues](using-tags.html) | Categorize and track issues more effectively with tags. |
| [Issue Search](search-for-issues.html) | Locate the issues that you want to find quickly and efficiently. |
| [Saved Searches](saved-search.html) | Save a search query and share it with your team so you can all work from the same page. |
| [Update Issues with Commands](commands.html) | Familiarize yourself with commands that let you update one or more issues at once. |
| [Notifications](notifications.html) | Manage how and where you receive notifications for which kind of updates. |

In addition to the topics in the documentation, we have a few external resources that you might find useful.

| Resource | Description |
| --- | --- |
| [YouTrack Demos](https://www.jetbrains.com/youtrack/documentation/) | Watch our series of short demo videos — the quickest way to get familiar with YouTrack. |
| [YouTrack Support Knowledge Base](https://youtrack.jetbrains.com/articles/SUPPORT-A-1029/YouTrack) | Read knowledge base articles from our support team - you might find some helpful information. |
