# Helpdesk License

> **Note: Helpdesk Availability**
> Helpdesk projects are available in YouTrack starting from version 2023.1.

Every YouTrack license that covers version 2023.1 or later supports helpdesk projects. To start using YouTrack Helpdesk and its features, [create your first helpdesk project](create-helpdesk-project.html).

* All YouTrack licenses support unlimited number of reporters in helpdesk projects. For details about reporters, see [Reporters](manage-user-types.html#reporters).

* All free subscription plans allow you to have up to 3 agent users free of charge. For details about agents, see [Agents](manage-user-types.html#agents).
