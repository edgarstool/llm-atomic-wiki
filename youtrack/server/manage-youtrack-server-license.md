# Managing Your YouTrack Server License

YouTrack Server installations use license keys to store the terms and limits for your current plan. The license key determines the number of users and helpdesk agents who can work in your installation, whether the license is perpetual or time-limited, and whether you can apply updates to a newer product version.

You can review the current license details in YouTrack. From the ![](https://resources.jetbrains.com/help/img/youtrack/2026.2/settings.svg) Administration menu, select `System Settings > Global Settings`, then select the License Details tab. For details, see [License Details](license-details.html).

## License Types

A license for up to 10 users and 3 helpdesk agents is granted for free. If you have multiple YouTrack Server installations, each installation must have its own license.

Commercial YouTrack Server usage is available as a perpetual license (for licenses purchased before June 23, 2026) or an annual user pack subscription (starting from June 23, 2026).

* Perpetual licenses let you continue using the licensed YouTrack Server version under the terms that were active when the license was issued. These licenses come with annual updates and support subscription. After the subscription expires, you can continue using the version covered by your license, but updates and technical support will no longer be available.

* Annual subscription-based licenses are valid until the date shown on the License Details tab. To continue using the installation under the same commercial terms, renew the user pack subscription and apply the renewed license key.

Customers who purchased YouTrack Server before June 23, 2026 can continue to use, renew, and upgrade their existing perpetual licenses under the current terms.

## Renew a Subscription

When you renew a user pack subscription or change the number of users or agents in your plan, you receive an updated license key.

Procedure: To apply a renewed license key:

1. From the ![](https://resources.jetbrains.com/help/img/youtrack/2026.2/settings.svg) Administration menu, select `System Settings > Global Settings`.

2. Select the License Details tab.

3. Paste the renewed key into the License key field.

4. Click the Save button.

To purchase a renewal or upgrade your current plan, click the Buy YouTrack button on the License Details tab.

## Update Users or Agents

If your installation needs to support more users or helpdesk agents than the free license allows, purchase a user pack subscription for the required limits. After the purchase, apply the new license key on the License Details tab.

You can also upgrade your annual subscription to a larger user pack at any time during the active subscription term. The upgraded user-pack limits take effect on the date of purchase and remain valid until the date shown on the License Details tab.

You can buy a user pack subscription for additional users or agents on the [Licenses](https://account.jetbrains.com/licenses) page in your JetBrains Account or from the [JetBrains website](https://www.jetbrains.com/youtrack/buy/?section=server&server-pricing-type=new). You must purchase the smallest user pack that covers your required number of users. For example, a 25-user pack and a 50-user pack cannot be combined to cover 75 users. Instead, you will need to buy a 100-user pack.

The Users and Agents values on the License Details tab of your YouTrack installation show how many active users and helpdesk agents are currently using your installation compared to the limits stored in your license key.

## Switch to the Free Plan

If you no longer need a commercial Server license, you can switch your installation to the free plan.

Procedure: To switch to the free plan:

1. From the ![](https://resources.jetbrains.com/help/img/youtrack/2026.2/settings.svg) Administration menu, select `System Settings > Global Settings`.

2. Select the License Details tab.

3. Click the switch to our Free Plan link.

The values in the License username and License key fields are replaced with the credentials for the free plan.

4. Click the Save button.

## Expired Subscriptions

If an annual subscription-based license is not renewed by the date shown as License valid until, the installation remains available for a seven-day grace period.

After the grace period ends, access is restricted until an administrator applies a renewed license key or switches the installation to the free plan. During this time, administrators can still open the license settings and work with backups.

* If the subscription is renewed during the seven-day grace period, the new term is backdated to the day after the previous subscription ended.

* If renewed after the grace period, the new term starts on the date of purchase.

If you own a perpetual license and your upgrade and support subscription is expired, you can continue using YouTrack for a selected number of users and agents covered by your latest user pack subscription. You are also able to upgrade your YouTrack installation to any product version released while your upgrade and support subscription was active. To continue to receive product updates and support for a perpetual license, you can renew your upgrade and support subscription any time until after one year since the subscription expiration date.
